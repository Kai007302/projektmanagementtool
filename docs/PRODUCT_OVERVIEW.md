# ProjectHub Product Overview

ProjectHub is an internal enterprise workspace for project execution and organizational knowledge.

## Primary areas

- Dashboard
- Projects
- Kanban
- Gantt
- Whiteboard
- Knowledge Hub / Knowledge Galaxy
- Search
- Notifications
- Administration

## External systems

- Microsoft Entra ID: identity
- Microsoft Graph / Outlook: email and optional calendar actions
- Webex: meetings and spaces

## Product philosophy

The platform has one authoritative task/project model. Views should compose existing domain objects rather than duplicate them.

Knowledge is equally first-class: articles, versions, relations and permissions are authoritative domain data; the visual Galaxy is only a visualization/navigation layer.

The interface should feel modern, calm and enterprise-grade. Animations are purposeful, subtle and accessible.
